1. Output throughput vs. concurrency, one line per configuration

Note on the statistics. The Statistic selector applies to TTFT, TPOT, ITL and E2E and picks how the requests of a cell are summarised: avg (mean), p50 (median), p90 / p95 / p99 (90% / 95% / 99% of requests are at or below the value) or max (the slowest request). Default is p90. TTFT, TPOT and E2E are per request; ITL pools the gaps between all streamed chunks of all requests, so its max is a single worst gap. Throughput is total output tokens per second per GPU and accept length is the mean over verify steps (MTP only), so neither depends on the selector. All values are recomputed from the per-request aiperf export of each run (profile_export.jsonl), TPOT = (E2E - TTFT) / (OSL - 1). Each cell is one run (n=1).
